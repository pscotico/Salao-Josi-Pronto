Na pasta do projeto, você pode executar:
npm start
Executa o aplicativo no modo de desenvolvimento.

Abra http://localhost:3000 para visualizar o aplicativo no navegador.

A página será recarregada quando você fizer alterações.

Você também poderá ver erros de análise de código (lint) no console.
npm test
Inicia o executor de testes no modo interativo de monitoramento.

Consulte a seção sobre execução de testes para obter mais informações.
npm run build
Compila o aplicativo para produção na pasta build.

Esse comando organiza corretamente os arquivos do React para produção e otimiza o aplicativo para obter o melhor desempenho.

A compilação é compactada, e os nomes dos arquivos incluem códigos hash.
